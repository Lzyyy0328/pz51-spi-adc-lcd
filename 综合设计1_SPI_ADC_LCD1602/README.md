# 综合设计1：基于SPI数据采集及显示功能设计（模式3）

## 1. 功能说明
- 基于 STC89C516 + ET2046 + LCD1602。
- 周期采样 2 个通道（默认 AIN0、AIN1），并缓存。
- 按键模式3：
  - KEY1：上一通道
  - KEY2：下一通道
  - KEY3：AUTO 开/关
- AUTO 打开后每 1 秒自动切到下一通道。
- LCD1602 显示：
  - 第1行：`CH:x ADC:yyyy`
  - 第2行：`U:x.xxxV AUTO:1/0`

## 2. 引脚定义
### LCD1602（来自实验29）
- 数据口：P0
- E：P2.7
- RW：P2.5
- RS：P2.6

### ET2046（软件SPI，来自实验27同口线）
- DOUT：P3.7
- CLK：P3.6
- DIN：P3.4
- CS：P3.5

### 按键（默认）
- KEY1：P3.1（上一通道）
- KEY2：P3.0（下一通道）
- KEY3：P3.2（AUTO开关）

> 若你的开发板按键口线不同，请修改 `key.c` 顶部的 `sbit KEYx` 定义。

## 3. 定时参数（`app.c`）
- 系统节拍：Timer0 1ms（`timer0.c`）
- 按键扫描周期：10ms
- 采样周期：100ms
- LCD刷新周期：200ms
- AUTO切换周期：1000ms
- 参考电压：`APP_VREF_MV = 3300`（mV）

## 4. ET2046 通道控制字（cmd）说明
在原实验27中，已有两条已使用映射：
- `0xA4`（示例标注为 AIN2）
- `0xE4`（示例标注为 AIN3）

本工程补充并定义：
- `ET2046_CMD_AIN0 = 0x84`
- `ET2046_CMD_AIN1 = 0xC4`
- `ET2046_CMD_AIN2 = 0xA4`
- `ET2046_CMD_AIN3 = 0xE4`

当前程序默认采样 AIN0/AIN1；若与你板卡丝印不一致，可在 `app.c` 的 `g_channel_cmds` 调整。

### 通道对应关系验证方法
1. 给目标通道单独施加已知电压（如 0.5V、1.0V、2.0V）。
2. 观察 LCD 第1行 ADC 和第2行电压是否随该通道变化。
3. 若变化对应错位，交换 `g_channel_cmds` 中命令次序或改为 AIN2/AIN3 命令测试。

## 5. 文件结构
- `main.c`：入口
- `app.c/h`：应用调度、显示格式化、模式逻辑
- `key.c/h`：三按键消抖与事件
- `timer0.c/h`：1ms 系统节拍
- `et2046.c/h`：软件SPI + ADC读取
- `lcd.c/h`：1602驱动（从实验29复制）

## 6. Keil C51 新建工程步骤
1. 在 Keil uVision 新建 C51 工程，芯片选 STC89C516（或兼容 8051 目标）。
2. 把本目录下 `.c/.h` 全部加入工程。
3. 使用默认 `REG52.H` 启动配置即可（与原实验一致）。
4. 编译下载后，上电观察 LCD 显示与按键逻辑。

- 第2行：`U:1.650V AUTO:1`
